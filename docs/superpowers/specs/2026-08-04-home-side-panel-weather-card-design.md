# HomeSidePanel 日期与天气卡片重设计

## 状态

- 日期：2026-08-04
- 设计状态：网页原型已确认，Android 实现完成，等待设备验收
- 实现范围：网页原型；Android Compose 实现不包含在本阶段

## 目标

将 HomeSidePanel 当前把时间、问候和天气信息混在一起的卡片拆成两个独立区域：

1. “日期与时间”卡片：只负责显示当前时间、日期和问候语，纯展示。
2. “天气”卡片：只负责显示天气数据，保留天气刷新和天气设置入口。

设计需要保持现有侧栏的 Material 3 视觉、暗色模式、Outlined 图标和紧凑可扫描的信息层级。

## 非目标

- 本阶段不修改 Android 生产代码。
- 不重新设计 HomeSidePanel 的头像、Tile、列表项、标题栏或侧滑交互。
- 不新增天气数据源，也不改变天气设置、定位、个人资料读取和错误处理逻辑。
- 不为日期与时间卡片增加配置、刷新或跳转能力。

## 设计方案

采用“主视觉温度 + 右侧天气状态”的布局方案。该方案让用户首先读到当前温度和天气状况，同时保留高低温、体感、湿度和风速等辅助信息，适合侧栏窄宽度和桌面宽宽度。

### 日期与时间卡片

- 使用 Material 3 `surfaceContainerLow`，不使用天气主题色，降低与下方天气卡片的视觉竞争。
- 保持现有卡片圆角和侧栏内边距体系。
- 第一行左侧显示大号 `HH:mm`，原型字号约 40–44px。
- 第一行右侧显示小号完整日期，并与时间文字下沿对齐。
- 第二行显示按时间段变化的问候语。
- 不显示“日期与时间”等可见标题。
- 不显示天气图标、天气数据或更新时间。
- 不响应点击、长按或刷新操作。
- 时间和问候内容为静态展示；原型可以随系统时间初始化，但不会模拟交互刷新。

### 天气卡片

- 保留现有天气卡片的天气主题容器色，并为浅色和暗色主题分别提供 Material 3 容器色。
- 顶部显示城市/地区，右侧显示最近更新时间。
- 主区采用左右分栏：
  - 左侧以当前温度作为唯一最大数字，下面显示体感温度。
  - 右侧显示 Outlined 天气图标和天气描述。
- 底部显示三个等宽指标：高温/低温、湿度、风速。
- 不使用渐变、装饰性光晕或额外嵌套卡片。
- 点击整张天气卡片刷新天气。
- 长按整张天气卡片进入天气设置预览。
- 天气错误继续通过 Toast 反馈；卡片内部不添加错误文本。
- 加载状态只替换天气主区内容，并保持卡片高度、左右分栏和底部指标区域稳定，避免布局跳动。

### 数据显示规则

- 当前温度使用带正负号的整数或接口提供的精度，单位使用 `°`。
- 高温和低温合并在同一指标中，避免重复标签。
- 体感温度作为当前温度下方的次级文字，不参与底部三列指标。
- 更新时间使用低强调文本，保留“刚刚”或短时间格式，不与城市名称竞争。
- 城市名和天气描述发生超长时使用单行省略；不能挤压当前温度或改变卡片高度。
- 天气图标使用现有天气图标映射的 Outlined 版本。

## 响应式布局

原型至少覆盖两种宽度：

- 窄侧栏：天气主区仍保持“温度 + 图标/描述”左右结构，底部指标压缩标签但不变成嵌套卡片。
- 宽桌面侧栏：增加主区左右留白，不放大卡片到失去侧栏密度；温度、天气图标和辅助指标维持同一信息层级。

两张卡片之间使用固定垂直间距。标题、数字、指标和图标均使用稳定尺寸，加载、长文本和交互状态不得造成其他内容位移。

## 主题与可访问性

- 提供浅色和暗色模式切换，所有表面、正文、次级文字和图标颜色均使用主题语义色。
- 保持 Material 3 的文字层级和足够的正文对比度。
- 天气卡片的点击区域为整张卡片；长按行为不能依赖小图标命中。
- 原型中的图标按钮提供可见的 hover/focus 状态和 `aria-label`。

## 网页原型范围

原型放置在：

```text
prototypes/home-side-panel-weather/
```

原型包含：

- 侧栏上下文和两张新卡片的完整排布。
- 浅色/暗色主题切换。
- 点击天气卡片时的短暂 loading 状态，并更新更新时间和模拟温度。
- 长按天气卡片切换到轻量天气设置预览，并可返回天气卡片。
- 代表性城市、天气描述、指标和长文本截断状态。
- 窄侧栏与宽桌面侧栏下的响应式布局。

原型不包含真实网络请求、真实定位权限、微信资料读取或 Android 代码。

## 验收标准

1. 日期与时间和天气在视觉上是两个清晰、独立的卡片。
2. 日期与时间卡片只展示日期、时间和问候，不出现天气字段或交互入口。
3. 天气卡片的第一视觉焦点是当前温度，第二焦点是天气图标和描述。
4. 高温/低温、湿度和风速能在底部一行被快速扫描。
5. 浅色、暗色、窄侧栏和宽桌面侧栏均无文字重叠、卡片跳动或溢出。
6. 点击刷新和长按设置预览可被清楚观察，日期与时间卡片保持无交互。
7. 原型不引入渐变背景、嵌套卡片或与现有侧栏不一致的装饰。
