# HomeSidePanel 交互与界面优化设计

## 目标

在不改变现有侧滑手势、宿主视图变换、edge-to-edge、FAB 和双标题栏行为的前提下，修复 HomeSidePanel 设置页返回层级、快捷入口跳转时序、关闭动画、点击反馈裁剪、天气设置布局、天气错误提示和一言署名样式。

## 返回层级

系统返回键按以下顺序处理：

1. 当前位于天气设置或一言设置时，只将 `cardMode` 切回 `CONTENT`，侧栏保持完全展开。
2. 当前位于侧栏首页时，播放正常侧栏关闭动画。
3. 侧栏完全关闭时，不消费返回键，继续交给微信。

标题栏返回按钮继续复用同一个 `closeCardSettings()` 行为。`HomeSidePanelSession.consumeBack()` 必须先询问 Controller 是否消费设置页返回，再决定是否关闭侧栏。

## 快捷入口与关闭动画

采用动画完成回调方案，不使用固定延迟。

- 扫一扫、收付款、收藏、朋友圈、视频号和 WeKit 设置：启动 one-shot 关闭动画，动画正常结束后再执行跳转。
- 清空未读：启动 one-shot 关闭动画，但立即执行清空操作，不等待动画结束。
- 点击 dim 区域，以及拖动后松手且手势状态机决定回到关闭态时，也使用 one-shot 关闭动画。
- 系统返回键关闭侧栏、切换到其他主页 Tab 等常规关闭行为继续使用原动画速度。
- one-shot 动画使用较短时长公式，完整关闭约 240ms；原常规完整关闭约 360ms。
- 如果 one-shot 动画被取消，等待动画的跳转回调不得执行。
- 如果侧栏已经关闭，等待关闭的动作可以立即执行。

`HomeSidePanelNavigator.closePanel` 接受可选完成回调。Session 将回调交给 `ValueAnimator` 的正常结束路径执行，Controller 根据快捷入口是否真正跳转决定等待或立即执行。

## 天气设置布局

天气设置页内容顺序调整为：

1. 页面标题。
2. 当前城市。
3. 自动检测、从个人资料读取。
4. 城市搜索输入框。
5. 搜索结果列表。

两个城市来源按钮保持等宽、等高，内部改为纵向排列图标和文字；文字强制单行并使用紧凑字号和内容间距，避免“从个人资料读取”折为两行。

搜索结果使用一个圆角 Material 3 Card：

- 每个城市使用整行可点击的 `ListItem`，不再为每项额外显示“选择”按钮。
- 主标题显示城市和区县，副标题显示省份。
- 右侧显示城市代码；当前已选城市额外显示选中图标或主色强调。
- 项目之间使用缩进分隔线。

## 点击反馈裁剪

天气卡片、一言卡片和三个顶部 Tile 的点击 Modifier 必须按相同圆角先 `clip(shape)`，再安装 `combinedClickable`，确保 ripple 被限制在卡片的圆角矩形内。卡片自身的 `shape` 与裁剪 shape 使用同一个局部变量，避免圆角不一致。

## 一言卡片

- 移除标题行右侧的刷新 `IconButton`。
- 点击整个卡片随机刷新、长按进入设置的行为保持不变。
- 署名单独占一行、填满宽度并右对齐。
- 同时有作者和出处时格式为 `—— 作者「出处」`。
- 只有作者时格式为 `—— 作者`。
- 只有出处时格式为 `——「出处」`。
- 作者和出处都为空时不显示署名。

## 天气错误提示

天气网络刷新、自动定位、个人资料城市读取、权限拒绝和城市匹配失败不再在天气卡片或天气设置页内显示错误 Text。Controller 通过一次性消息流发布天气错误，Compose 在当前 Session 内收集并调用现有 Toast 工具显示。

- 每次失败操作都发布一次 Toast，即使错误文字与上次相同。
- 有缓存时天气卡片继续显示缓存，不再附加错误行。
- 无缓存时卡片显示中性的天气占位文案，不把错误文字嵌入卡片。
- 取消协程不发布 Toast。

## 日志

删除 HomeSidePanel 宿主 UI 中用于观察初始化、触摸、拖动、视图查找、变换和 edge-to-edge 的 `WeLogger.i` 调试日志。保留真正的错误、异常和兼容性失败日志，不修改天气、一言、资料与定位仓库的错误日志。

## 测试与验收

新增或调整纯 JVM 测试覆盖：

- 设置页返回只回到侧栏首页，首页返回才请求关闭侧栏。
- 需要跳转的快捷入口只在关闭完成回调后执行；清空未读立即执行。
- one-shot 关闭时长短于常规关闭时长，完整关闭目标约 240ms。
- 动画取消时不执行待跳转回调。
- 一言署名四种组合的精确格式。
- 天气错误每次通过一次性消息发布，不依赖页面内错误 Text。

最终验证：

```bash
./gradlew :app:testStandardDebugUnitTest --tests 'dev.ujhhgtg.wekit.features.items.beautify.home_screen_panel.*'
./gradlew :app:testStandardDebugUnitTest
./x build
git diff --check
```

真机验收必须确认返回层级、按钮单行布局、搜索列表点击、Toast、ripple 圆角裁剪、跳转动画无卡顿、dim/手势 one-shot 关闭速度和一言署名均符合预期。

## 实施边界

- 不新增自定义选项。
- 不使用 `getIdentifier`。
- 不新增 `PhoneWindow` Hook。
- 不修改 HomeSidePanel 之外的现有功能行为。
- 不重复 DexKit 全版本测试，除非实施过程中修改 Dex 声明或解析逻辑。
