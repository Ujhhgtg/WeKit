# 自动接收转账

入口：WeKit 设置 → 功能 → 红包与支付 → 自动接收转账。

收到待收款的转账消息后，按规则调用微信接收流程。首次启用需要确认功能提示。

点击功能配置全局、会话和群成员覆盖规则，未覆盖的项目继承上一级。可设置是否接收、时间范围、金额区间、备注关键字、延迟、通知及自动回复。金额区间以元填写；开启后非空边界必须有效。

默认全局接收开启，延迟基础 500 ms、随机浮动 300 ms；金额、时间和关键字筛选、通知和自动回复默认关闭。配置后按界面保存。

自己是付款方的转账会忽略，不提供「接收自己转账」选项。模块只处理适合收款的消息状态，最终以微信确认的收款结果为准。配置保存于 `<模块数据>/transfer_settings.json`。
