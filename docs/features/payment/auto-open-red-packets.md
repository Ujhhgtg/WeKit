# 自动抢红包

入口：WeKit 设置 → 功能 → 红包与支付 → 自动抢红包。

监听红包消息，按配置规则自动领取。首次开启需要确认功能提示。

## 规则与优先级

点击功能可配置全局规则、会话规则和群成员规则。会话未覆盖的项目继承全局设置，群成员覆盖在对应会话规则基础上生效。

| 设置 | 用途 / 初始行为 |
| --- | --- |
| 是否领取 | 全局默认开启 |
| 领取自己的红包 | 默认关闭 |
| 领取方式 | NETWORK 发包，或 CLICK 点击；默认 NETWORK |
| 时间范围 | 限制运行时段 |
| 关键字 / 排除关键字 | 按红包内容筛选，支持字符串列表或正则 |
| 延迟 | 默认基础 500 ms、随机浮动 300 ms，可关闭 |
| 通知 | 领取成功后提示，默认关闭 |
| 自动回复 | 领取成功后发送配置内容，默认关闭 |

NETWORK 通过微信请求流程领取；CLICK 走红包页面的接收和按钮点击流程，不是把两种方式同时执行。页面、网络和微信服务端条件仍会影响领取结果。

## 使用

先设置默认规则，再为需要不同处理的会话或群成员添加覆盖项，按对话框的保存/确认操作提交。自动回复中的 `$amount` 会替换为金额。开启后收到符合规则的红包才会触发。

配置保存在 `<模块数据>/red_packet_settings.json`。请求成功前不能把本地触发当作已领取。
