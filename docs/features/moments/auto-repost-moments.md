# 自动转发

入口：WeKit 设置 → 功能 → 朋友圈 → 自动转发。

浏览或同步朋友圈时，按规则将目标联系人的朋友圈转发到自己的朋友圈。

## 配置

开启后点击功能，配置全局规则和联系人覆盖规则。可以分别控制是否处理、处理模式、操作间隔、时间范围、关键字、内容类型和内容时效；联系人未覆盖的项目继承全局设置。

处理模式可选浏览时处理或处理已加载内容。后者会检查微信本地已加载/同步的朋友圈，不代表能读取未获得访问权限的内容。可配合[自动刷新](auto-refresh.md)更新本地内容。

## 使用前检查

先选择目标联系人并核对规则，再开始浏览或同步。成功转发的记录用于避免重复发送；已删除或撤回的内容会跳过。

转发会实际发布到自己的朋友圈，媒体下载或发送失败时不应视为已发布。朋友圈可见范围、服务端限制和素材可用性仍以微信实际结果为准。
