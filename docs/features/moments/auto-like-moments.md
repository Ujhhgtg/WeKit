# 自动点赞

入口：WeKit 设置 → 功能 → 朋友圈 → 自动点赞。

按规则自动点赞或取消点赞。开启后点击功能，配置全局规则及联系人覆盖，未覆盖的项目继承全局设置。

可选择浏览时处理或处理所有已加载内容，并配置动作、操作间隔、时间范围、关键字、内容类型和发布时间范围。默认模式为浏览时处理、动作为点赞。

功能只处理微信已加载的内容，不会获得额外的朋友圈访问权限。动作会实际提交到微信，以返回结果为准。

朋友圈防撤回保留的动态只供本地查看，不会参与自动点赞或取消点赞。微信同步时已标记为删除或不可见的动态同样会跳过，包括没有文字、无法添加防撤回水印的动态。

为避免集中发送，自动点赞及取消点赞的操作间隔至少为 2 秒；配置更长的间隔时使用配置值。已提交的动作按微信账号保存在本地，刷新或重启微信不会因点赞状态尚未同步或发送失败而反复提交同一动作。切换为相反动作后仍可处理同一条动态。已加入微信发送队列不代表服务器已确认成功，发送失败时请在微信内手动处理。
