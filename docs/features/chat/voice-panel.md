# 语音面板

入口：WeKit 设置 → 功能 → 聊天 → 语音面板。

## 打开与发送

开启功能后，在聊天中长按语音按钮打开面板。新建本地语音包后，可以从文件或目录导入音频，预览后发送到当前聊天。也可通过[保存到面板](save-to-panel.md)收集聊天中的语音。

面板支持最近使用、最常使用、本地包、在线语音包和共享语音包；可以搜索、排序、重命名和删除本地内容。单条导入语音不能超过 10 MiB，并且必须是模块可识别、可转换的音频格式。

## 文字转语音与音色

进入「文字转语音」，选择可用的提供商与音色，填写文本，等待合成和必要的 SILK 转换后再发送。系统 TTS 需要设备上有可用引擎和语音数据；在线提供商需要网络连接，服务失败时不会生成有效语音。

音色管理支持导入音色、从面板选择克隆来源以及试听示例。使用他人声音前应取得许可；选择音色不代表服务一定支持该输入或能成功合成。

## 共享与设置

共享语音包支持新建、上传和提交审核。上传会向在线服务发送音频；包确认提交审核后不能再删除或修改名字，应先检查名称与内容。

面板设置包括发送后自动关闭、导航位置记忆、历史数量、布局、下载和转换并发。默认历史数量 50、下载并发 4、转换并发 2。

本地包位于 `<模块数据>/voice_panel/`，音色目录为其下的 `clone_voices/`。删除包会清理本地内容。预览、下载、转换和发送有各自的失败提示；以操作结果为准。
