# 对话分组

入口：WeKit 设置 → 功能 → 聊天 → 对话分组。

在首页顶部按分组筛选对话。初始提供全部、未读、群聊、好友和公众号；可以创建自定义分组，不限于这五个标签。

## 管理分组

长按分组标签打开菜单，可新建、编辑、排序或删除分组。「全部」可参与排序，编辑时只能修改名称，不能删除；名称留空时使用内置的本地化「全部」。

分组可以手动选择对话，也可以自动收集未读、群聊、好友或公众号。高级用法支持 SQL 规则，设置页给出可用字段和示例；规则只应筛选你理解的数据。隐藏联系人仍按当前隐藏规则处理。

创建或编辑自动分组时，名称可以留空，将使用当前自动模式对应的内置本地化名称；手动分组和 SQL 分组必须填写名称。

## 显示方式

点击功能配置：

- 内容宽度：默认选项，标签总宽度较小时居中，超出时横向滚动。
- 等宽布局：标签平分整行宽度。
- 显示未读：默认开启，在分组标签上显示未读数字和红点。
- 计入公众号未读：默认关闭，仅在开启「显示未读」时显示此选项，开关时以动画展开或收起。

分组数据保存在 `<模块数据>/conversation_groups.json`。若主页下滑「最近」页与标签手势冲突，可以启用[隐藏主页下滑「最近」页](../beautify/hide-home-screen-swipe-down-page.md)。
