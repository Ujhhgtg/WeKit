# 聊天输入栏操作

在「WeKit 设置 → 功能 → 聊天」分别启用需要的功能后，长按聊天输入栏的发送按钮或加号按钮打开操作菜单。

- [发送卡片消息](send-card-message.md)：将输入框中的有效 appmsg XML 发送为卡片。
- [发送语音文件](send-voice-file.md)：选择本地音频发送。
- [@所有人](mention-members.md)：选择群成员并发送提醒。
- [安全消息发送](send-sec-msg.md)：按配置模式发送带安全属性的文本。

长按表情按钮打开[表情面板](sticker-panel.md)，长按语音按钮打开[语音面板](voice-panel.md)，需分别启用相应功能。
