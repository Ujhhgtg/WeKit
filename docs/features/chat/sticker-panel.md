# 表情面板

入口：WeKit 设置 → 功能 → 聊天 → 表情面板。

## 打开与首次使用

开启功能后进入聊天，长按表情按钮打开面板。在「本地表情包」中新建一个包，再导入图片或目录；也可启用[保存到面板](save-to-panel.md)，从聊天消息直接收集表情。选择表情发送到当前聊天。

面板提供最近使用、最常使用、本地包、在线包和搜索。可以对包重命名、删除、排序，修改表情名称或封面；长按「自定义」排序项进入拖动排序。

## 导入与在线内容

- 本地文件/目录：通过系统文件选择器授权读取，不要求手工创建微信数据库记录。
- 微信原生表情：从微信已保存的表情中导入，资源下载成功后才能使用。
- Telegram：支持从可读取的 Telegram 数据库导入，以及通过 Telegram Bot API 获取表情包；API 方式需先在面板设置中填写有效的 Bot Token。读取其他应用私有数据取决于设备权限，不能保证普通文件选择器能访问。
- 在线包：可以搜索、预览、保存到本地，并对记录了在线来源的本地包执行更新。在线搜索与上传由对应服务提供，网络或服务不可用时会报错。

上传表情包会把内容提交到在线服务，需要在确认窗口确认；本地导入不等于上传。

## 设置与数据

面板设置可调整列数、包布局、历史数量、发送后自动关闭、操作栏换行、导航位置记忆、下载/转换并发和动画转换选项。默认发送后关闭、记忆本次微信运行期间的导航位置；下载并发 4，转换并发 2，历史数量 50。

本地数据位于 `<模块数据>/sticker_panel/`，转换缓存位于模块缓存的 `panels/`。删除本地包会删除其中的本地表情。格式不受支持、源文件无法读取或下载失败时，不能保证完成导入或发送。
