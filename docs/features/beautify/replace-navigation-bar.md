# 美化首页底部导航栏

入口：WeKit 设置 → 功能 → 界面美化 → 美化首页底部导航栏。

用 Material Design 风格底栏替换微信首页导航，支持标准底栏和悬浮底栏。

## 外观与行为

点击功能可以配置悬浮样式、液态玻璃、模糊半径、动态重力高光、标签文字、底栏缩放、页面切换动画、自动隐藏以及「发现」角标。

默认启用悬浮底栏、液态玻璃、页面切换动画和发现角标；自动隐藏、动态重力高光、隐藏标签默认关闭。默认模糊半径为 8，缩放为 100%。动态重力高光会持续使用旋转传感器。

## 页面管理

进入「页面管理」，开关主页、通讯录、发现和我，并长按手柄调整顺序。确认后，下次启动微信生效；关闭全部页面会隐藏底栏。

自动隐藏开启时，在主页会话列表向下滑动隐藏底栏，向上滑动恢复。
