# 莫奈引擎模块生成器

入口：WeKit 设置 → 功能 → 界面美化 → 莫奈引擎模块生成器。

## 前置条件

需要 Android 12 或更高版本、可用的「莫奈引擎模块生成器」扩展包，以及可安装模块的 Root 管理器。点击功能时，缺少扩展包会提示安装；损坏或不兼容的包需要重新下载。

## 生成与安装

1. 点击功能，选择气泡样式：现代圆角、经典微信或 Pro 圆角。
2. 选择是否启用输入栏、引用与支付键盘圆角，设置底栏为纯色或半透明莫奈，并选择当前用户或全部用户。
3. 点击「生成」，等待读取微信 APK、解析和生成资源完成。进度窗口会显示当前阶段，失败时显示所在阶段与原因。
4. 生成结果保存为下载目录中的 `monet_engine_module.zip`，以完成界面给出的实际路径为准。
5. 通过 Magisk、KernelSU、APatch 或其衍生 Root 管理器安装该 ZIP，启用「莫奈引擎模块生成器」开关并重启。KernelSU/APatch 中还需为微信关闭「卸载模块」选项。

默认使用现代圆角、启用多场景圆角、纯色底栏和当前用户范围。生成结果针对当前安装的微信资源；升级微信后应重新生成并检查效果。

与[模块主题取色](monet-engine.md)不同，这里生成需要安装的资源覆盖模块。输出成功只表示生成完成，不能代替安装后对实际微信界面的检查。
