# 主页侧滑面板

入口：WeKit 设置 → 功能 → 界面美化 → 主页侧滑面板。

## 使用

开启后回到微信主页，通过侧滑手势打开面板；也可以在启用标题栏「我」组件后点击对应入口打开。点击面板外的遮罩或返回可关闭。

侧栏可以放置日期与时间、天气、钱包、一言、图片，以及横向磁贴或纵向动作列表。动作包括扫一扫、收付款、收藏、朋友圈、视频号、清空未读和 WeKit 设置等。

## 编辑布局

进入「编辑模式」，添加或删除卡片，并拖动调整顺序；动作卡片内的动作也可以排序。完成后点击「保存侧栏布局」。关闭并放弃更改会丢弃本次布局草稿，保存失败时草稿仍保留。

图片卡片可选择或替换图片，使用裁剪填充、完整显示、拉伸填充或适应比例，并调整卡片高度。

## 卡片设置

- 日期与时间：选择是否显示农历。
- 天气：自动定位、读取个人资料地区，或搜索城市。自动定位需要系统定位服务和相应权限；失败时可以手动选城。
- 钱包：可默认隐藏余额；点击临时显示后，关闭侧栏会恢复隐藏。
- 一言：选择分类、长度范围，以及是否显示来源和作者；读取内容需要网络。

侧栏设置还可在微信标题栏显示「我」组件，并隐藏微信标题文字。部分动作依赖当前微信是否提供对应页面，无法打开时会提示失败。
