# 莫奈引擎

> 在运行时重新着色微信自身的界面资源，跟随 WeKit 主题色 \[需 SDK >= 30\]

## 类别

界面美化

## 类型

可开关，可点击配置

## 描述

在微信进程内直接替换微信自身的颜色与形状资源（背景、文字、气泡、输入栏、支付键盘等），无需 Root、模块或重启。

颜色跟随 WeKit 设置 → 主题：开启「动态壁纸取色」时使用系统壁纸配色（Android 14+ 直接引用系统莫奈色，更早版本由壁纸强调色生成），否则由种子颜色、调色板样式与颜色规格生成。深色与浅色模式各自使用对应的配色。

首次开启、点击「重新分析微信资源」以及微信更新后首次打开时，都会弹出分析进度窗口（通常十几秒），结果按微信版本缓存；分析完成后提示重启微信以刷新全部界面。

点击功能可配置：

- 气泡样式：现代圆角气泡、经典微信气泡、Pro 圆角气泡。
- 输入栏、引用与支付键盘圆角。
- 未读角标与错误色（默认关闭）：同时重新着色微信表示错误与危险操作的红色，包括未读角标、发送失败图标、删除 / 移除操作与危险对话框按钮。
- 资源绑定：显示已解析的角色数，可重新分析微信资源。

主题与选项修改即时生效，但只影响之后打开的界面；已打开的界面需重新进入，重启微信可刷新全部界面。底部导航栏不受此功能影响；未开启「未读角标与错误色」时，错误与危险操作的红色保持微信原样。

WeKit 自身绘制的界面同样跟随莫奈配色：「美化对话列表」的岛式布局、对话分组的标签栏与浮动岛以及主屏幕 FAB。

需要 Android 11+ (SDK 30)。桌面图标与系统启动画面属于微信进程之外，不在覆盖范围内。
