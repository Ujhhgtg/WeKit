# WeAgent

入口：WeKit 设置 → 功能 → 系统与隐私 → WeAgent。

WeAgent 提供悬浮对话、模型调用、工具、MCP、技能与触发器。点击功能直接进入设置；此入口没有总开关，悬浮入口是否显示由「悬浮窗模式」控制，默认关闭。

## 首次配置

1. 打开「模型提供商」，添加服务端地址与所需凭据，并添加可用模型。使用自己的服务账户；模块不附送模型服务额度。
2. 在默认设置中选择默认模型。需要时选择小模型；未单独选择时沿用主模型。
3. 为微信授予悬浮窗权限，设置悬浮窗模式为仅前台显示或始终显示。
4. 打开悬浮对话，选择模型后发送消息。先用普通文本确认服务配置可用，再启用所需工具。

## 能力配置

| 入口 | 用途 |
| --- | --- |
| 模型提供商 | 管理远程模型与本地 llama 提供商；本地模型另需运行时扩展与模型文件 |
| MCP 服务器 | 配置外部工具服务，连接后检查可用工具 |
| Linux 环境 | 管理供命令和开发工具使用的执行环境，按页面要求安装对应扩展/文件系统 |
| 外部服务 | 配置其他集成服务 |
| 提示词 | 管理系统提示与其他提示规则 |
| 技能 | 管理可供代理使用的技能 |
| 触发器 | 配置何时触发代理操作 |

正在运行时发送新消息，可选择排队等本轮结束，或在下一次请求中作为引导。实际可用的功能由所选模型、工具和执行环境决定。

## 权限与数据

默认权限级别可以选择请求批准、自动编辑、自动批准或完全访问。工具可能读取聊天、文件或调用外部服务；选择前应明确授予哪些能力，涉及发送或写入时核对实际请求。

发送到远程模型的内容由你配置的服务处理。提供商凭据、MCP 地址、聊天上下文及执行环境中的文件均应按自身隐私要求管理。关闭悬浮入口只是隐藏界面，不应当作撤销外部服务权限。

## 故障排查

无悬浮入口时检查悬浮窗模式和微信权限；模型失败时检查地址、凭据与模型名；本地模型或 Linux 环境失败时检查扩展包安装状态和诊断信息。模块构建通过并不代表设备上的本地推理或执行环境已经验证。
