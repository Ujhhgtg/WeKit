# 隐藏联系人

入口：WeKit 设置 → 功能 → 联系人与群组 → 隐藏联系人。

按隐藏列表控制联系人在会话、通讯录、搜索、朋友圈及通知/通话相关界面的显示。开启后点击「配置隐藏列表」选择联系人。

## 临时显隐

在聊天输入栏使用 `#show` 临时显示隐藏联系人，使用 `#hide` 恢复隐藏。也可启用「三击标题切换显隐」，或设置定时显示/隐藏；这些操作不修改已保存的隐藏列表。

锁屏和摇动设备会关闭相关隐藏聊天页面。功能用于本机显示管理，不删除联系人或聊天记录，也不保证所有微信页面和外部通知历史都没有痕迹。

## 音视频通话

「自动拒绝音视频通话」默认关闭：关闭时隐藏来电界面，对方可能一直响铃到超时；开启后向对方发送拒接。按需要选择，避免把隐藏来电视为没有收到来电。
