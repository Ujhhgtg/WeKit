# WeKit Translation Glossary

本表规定用户界面的统一措辞。它不授权翻译 DexKit 锚点、宿主字符串、协议字段、日志或代码
标识符。

| English | 简体中文 | 繁體中文 | Rule |
| --- | --- | --- | --- |
| WeKit | WeKit | WeKit | 产品名不翻译。 |
| WeChat | 微信 | 微信 | 使用官方中文产品名。 |
| Xposed | Xposed | Xposed | 不翻译。 |
| Zygisk | Zygisk | Zygisk | 不翻译。 |
| DexKit | DexKit | DexKit | 不翻译。 |
| Moments | 朋友圈 | 朋友圈 | 英语 UI 使用 “Moments”；代码和 Dex 术语仍可使用 `sns`。 |
| Channels | 视频号 | 視訊號 | 仅用于面向用户的产品术语，不替换代码标识符。 |
| group | 群组 | 群組 | WeKit 面向用户的术语；微信内部可能使用 `chatroom`。 |
| chatroom | 群聊 | 群聊 | 仅在描述微信自身内部概念时使用。 |
| host | 宿主 | 宿主 | 指微信应用进程或包。 |
| module | 模块 | 模組 | 除非上下文另有说明，否则指 WeKit。 |
| feature | 功能 | 功能 | 指面向用户的功能开关或能力。 |
